# Sehat Nama Pro

Intelligent guide to Pakistani medicines: search brands, generics and alternatives. For information only, not medical advice.

**Live app:** https://ubaid792792.github.io/sehat-nama/

## How to use

Open `index.html`. An optional `sehatnama_database.md` placed next to it is loaded automatically; otherwise use the in-app file picker.

## Privacy

No API keys or personal data are stored in this repository.
